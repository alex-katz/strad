# Добыть артефакт для Виктора

**Статус:** Активно
**Выдал:** [Виктор Валакиевич](../../characters/npc/viktor-vallakovich.md)

## Цель

Найти [башню волшебника Хасана](../../locations/khasans-tower.md) на [озере Бараток](../../locations/lake-baratok.md), добыть один из его артефактов и принести его [Виктору Валакиевичу](../../characters/npc/viktor-vallakovich.md). В обмен он пообещал поделиться информацией о башне из найденной им книги.

## Прогресс

Мы выяснили, что к озеру нас могут провести [местные охотники](../../locations/hunters-house.md).
